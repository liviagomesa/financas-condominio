# Checklist para `/speckit.specify` (o quê)

- Qual é o problema de negócio que essa feature resolve, especificamente?
- Quais entidades (novas ou existentes) essa feature usa, e quais atributos cada uma tem?
- Quais são os casos de uso ou fluxos principais, passo a passo, do ponto de vista do usuário?
- Existe alguma regra de negócio específica dessa feature (cálculo, validação, condição)?
- Quais são os edge cases conhecidos (o que acontece quando falta dado, quando há conflito, quando algo já existe)?
- O que está explicitamente fora do escopo dessa feature, pra não virar scope creep?
- Essa feature altera comportamento de algo que já existe, ou é inteiramente nova?
